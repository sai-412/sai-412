### 🚀 Projekte

#### SmartClock
Ein Projekt mit einem MicroMod als Mikrocontroller zur Entwicklung einer intelligenten Uhr, die nicht nur die Zeit anzeigt, sondern auch im Alltag nützlich ist.
* **Umweltsensoren:** Misst präzise Raumtemperatur und CO2-Werte.
* **Timer-Funktion:** Integrierte Timer-Funktionen für den täglichen Gebrauch.
* **Zeitanzeige:** Klare und zuverlässige Zeitanzeige für den Alltag.
* **Akustische Warnungen:** Integrierter Buzzer zur Ausgabe von Warnsignalen bei Bedarf.
* **Technologien:** Embedded Systems, MicroMod-Hardware, Git und Programmierung.

#### Face Recognition Service (M346 – Cloudlösungen)
Ein Team-Projekt, das einen serverlosen Gesichtserkennungs-Service auf AWS realisiert. Ein Bild wird in einen S3-Bucket hochgeladen, was per Event-Trigger eine Lambda-Funktion auslöst, die über AWS Rekognition eine Analyse durchführt und das Ergebnis als JSON im Output-Bucket speichert.
* **Cloud-Infrastruktur:** AWS S3 (Input-/Output-Buckets), AWS Lambda, AWS Rekognition
* **Automatisierung:** Vollständig automatisiertes Setup, Deployment und Reset via Shell-Skripte
* **Technologien:** AWS CLI, .NET 8 (C#), Bash-Scripting
